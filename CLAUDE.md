# WarZone / Frontline USA — project guide for Claude Code

## What this is
A single-player, real-time strategy game for the browser (mobile-first), set on a map of the United States. It is inspired by Supremacy: World War 3, but everything (names, art, nations) is original. Do not copy assets, branding or names from that game. The long-term plan is to wrap it as a phone app later.

The owner (Justin) asked for these changes relative to the original game:
1. No forced ending. Players can keep playing the late game ("ride the late game and continue").
2. No pay-to-win and no monetization of any kind.
3. Computer nations must actually do things (the original's AI is "useless"), because this is single-player.
4. More diplomacy between nations.
5. Keep the combat feel, which he likes.
6. Browser first, US map only for now (world map is a possible later step).

## Repo layout
- `sim.js`: the whole simulation, economy, combat, diplomacy and AI. Defines `const SIM = (function(){...})()` and expects a global `MAP`.
- `ui.js`: the interface, one IIFE (SVG map, pan/zoom, panels, modals, save/load, frame loop).
- `template.html`: CSS and markup with placeholders `/*MAPDATA*/ /*SIM*/ /*UI*/`.
- `mapdata.json`: generated map: `{w,h,provinces[{id,st,name,cx,cy,px,py,area,pw,coast,d,nbrs}],borders[{a,b,d}],stateLines,coast,sea[[a,b,dist]],states[{st,name,x,y}],nodes[[x,y,pid]],roads[[a,b,(lane distance)]]}`. 217 city provinces, 542 borders, 812 road nodes, 1859 roads. `cx,cy` is the anchor for badges and routes, `px,py` the city dot, `pw` the province's share of its state's population.
- `buildmap.mjs`: regenerates `mapdata.json` from us-atlas `counties-albers-10m` (975x610 Albers USA) and city data from `all-the-cities` (GeoNames). Each state is split into a few provinces named after their main city: seed cities are picked by population and spacing, and counties join the nearest seed through county adjacency, so provinces stay contiguous. `RENAME`, `SKIP`, `NOT_COASTAL` and `K_OVERRIDE` hold hand fixes. Sea lanes: Anchorage-Seattle and Honolulu-Los Angeles (330), plus short lanes that connect islands inside a state.
- `buildroads.mjs`: adds the road network to `mapdata.json` (run after `buildmap.mjs`; needs nothing from npm). Node i < 217 is province i's city (`px,py`); the rest are waypoints scattered through each province (Poisson disk, spacing 15), joined by a Gabriel graph. Roads stay inside the one or two provinces they link, each province's roads are connected, every neighbour pair gets a road, and sea lanes become city-to-city roads that carry the lane distance.
- `make.js`: assembles everything into one self-contained `frontline-usa.html` (about 207 KB). Copy that to `dist/index.html`, which is the playable file.
- `test.js`: headless all-AI run: `node test.js <minutes> <easy|normal|hard>`.
- `smoke.js`: jsdom UI smoke test (needs `npm install`, and reads the built `frontline-usa.html`, so run `node make.js` first).

Workflow: edit `sim.js` / `ui.js` / `template.html`, run `node make.js`, copy `frontline-usa.html` to `dist/index.html`, commit.

## Hard constraints
- Output must stay a single self-contained HTML file with no external libraries and no network calls. The only external resource allowed is Google Fonts (Big Shoulders Display, Barlow Semi Condensed, IBM Plex Mono), and every font needs a fallback stack. The game is published as a Claude artifact whose CSP blocks everything else.
- Vanilla JS, inline SVG map. Layout must work at 400px wide with no horizontal page scroll. Touch is the primary input.
- Light and dark themes via CSS tokens on `:root` (dark via `prefers-color-scheme` and `[data-theme]`). Keep the `claude:viewport-fit-sides` meta and side gutters.
- No monetization, ads or pay-to-win mechanics, ever.
- Saves go to `localStorage` key `frontline_usa_save_v1`, always inside try/catch. The save carries `G.v` (`SAVE_V`, now 5, bumped for the road network); `SIM.saveOk` rejects saves from any other version.

## Game design
**Nations.** 10 fictional regional nations covering all 51 provinces: Pacific Republic, Mountain Pact, Southwest Compact, Heartland Union, Lakes League, Delta Pact, Seaboard Commonwealth, Appalachian Federation, Atlantic Dominion, New England Concord. Each has a personality (warmonger, opportunist, turtle, diplomat, builder), a capital and a colour. Conquered provinces can revolt back to the original owner or become a "Free State" nation.

**Provinces.** Each state is split into city provinces (`PS[pid].st` is the state). The old per-state numbers in `STATE` (population, terrain, resource list) are shared out by `pw`. Nations still own whole states at the start; the capital is the biggest province of the capital state (`mainOf`).

**Economy.** Seven resources (`RES`): cash, manpower, supplies, components, fuel, electronics, rare materials, plus research points (`n.rp`). Every province makes cash and manpower from population, some supplies, and one primary resource (`PS.res`, from the state's resource list). Capitals make a trickle of everything. Units cost cash upkeep. Costs are objects keyed by resource (`canPay`, `pay`). Stocks of non-cash resources tend to pile up, and cash is the usual limit.

**Market.** One world market (`G.mkt`) for manpower and the five materials (`MKT_RES`), traded for cash. Each has a base price (`MKT_BASE`) times a price index `G.mkt.idx[k]` that falls by a factor of e for every `MKT_DEPTH` (800) units sold and rises the same way when bought, clamped to 0.3-3, and drifts back towards 1 with a little noise in `mktTick` (`G.mkt.prev` is a snapshot from the last minute, for trend arrows). `mktQuote` prices a trade by walking the index as it fills, plus a fee (`mktFee`: 10%, 5% with any trade pact). `cmdTrade(nat, k, q)` buys (q > 0) or sells (q < 0) and adds to `n.mktNet`. Auto-sell (`n.auto[k]`, steps in `AUTO_STEPS`, set by `cmdAutoSell`) sells anything above the chosen level every 10 seconds, also while away. `aiMarket` (every AI think) sells above 300 (manpower 250) while the index is above 0.55 (or when broke) and buys 40 of anything under 30 when rich. In AI-only runs the AI dumping keeps manpower and supplies near the floor and the rest around half price; trade adds roughly 10-15% to an AI nation's cash.

**City buildings.** Data-driven `BLD` table in `sim.js`, stored per province in `p.b[kind]` (default max level 3, `max` overrides). Construction queue `p.bq` (max 3 projects, pauses during battle or occupation, cleared on capture; `plannedLvl` counts queued levels; cancel pops the last one for half its cost). Army base (needed for artillery and armor), air base (needed for air), naval base (coastal only, port cash), recruiting office, arms industry, hospital (less damage for the owner's troops), fortifications (`fort`, max 5, +20% defence, slower capture, bigger garrison), bunkers (`bunk`, garrison-only damage reduction, +2 garrison, faster refill), anti-air (`aa`, flak against hostile air plus a defence bonus against air attacks), research lab, infrastructure. Level n costs n times the base and takes 1 + 0.6(n-1) times as long. The UI lists whatever is in `BLD`. Capture drops every building one level. AI: `aiBuild` scores projects (production first, defence by threat, anti-air by threat and the rivals' air share plus one over the capital, economy by shortage) and keeps 40 of each resource for units.

**Units.** `UNITS` in `sim.js`, 16 types in four categories (`CATS`). Ground: rifle infantry `inf`, mechanized `mech`, airborne `abn`, special forces `sf`, field artillery `art`, battle tank `arm`, mobile flak `flak`. Air: attack helicopter `heli`, interceptor `ftr`, strike bomber `bmb`, patrol aircraft `pat`. Sea: patrol boat `pb`, destroyer `dd`, attack submarine `sub`, strike cruiser `cru`. Missile: cruise missile `msl`. Each has `cls` (combat class), `dom` (`land`, `sea` or `msl`), `need` (building levels, e.g. bombers need air base 2, cruisers naval base 3, missiles an arms industry), `fast` (buildings that speed training), optional `vs` (own multipliers over the class table) and `ign` (share of defence bonuses ignored: artillery, special forces, missiles 0.5). The class table `CM` and `TWC` generate `MULT` and `TW`. Unit cash costs are low and material costs high, so cash, components and fuel are the usual limits.
- Armies are one domain each (`domOf`): land armies (ground plus aircraft, which march together; an army of only airborne troops and aircraft flies), fleets and missile salvos. Training, `mergeIdle` and `cmdMerge` keep them apart.
- Fleets sail the sea graph `SEA_NB` (coastal provinces that touch, the map's sea lanes, and the hand links in `SEA_LINKS`). There are three separate waters: Atlantic and Gulf (Maine to Texas), Pacific with Alaska and Hawaii, and the Great Lakes. Ships fight and shell ports but cannot capture.
- Missiles (`missileOk`, `MSL_RANGE` 260, `inRange`, which blocks shots into or out of the Alaska and Hawaii insets) fly straight to an enemy province, are partly shot down by `intercept` (city anti-air, flak, interceptors, destroyers), hit once, may knock a level off forts, bunkers or anti-air, and are then spent. Idle salvos take no part in battles and are destroyed if their city falls. The UI asks for a second tap before a launch.

**Research.** `TECH` in `sim.js`: 17 techs in five branches (`BRANCHES`: Ground, Air, Sea, Missile, Economy), tiers 1-3 costing `TIER_RP` 120/300/600 points, some with `req` prerequisites. One project at a time (`n.rs = {k, got, need}`); research points pour into it at `pourRate` (1.5 times the income plus 0.3 per second, so a saved stock helps but does not finish a tech instantly). Points come from the capital (0.15/s) and research labs (0.25 per level). Finished techs are in `n.tech`; `calcMods` sums their `fx` into `n.mods` (read through `modsOf`): attack and toughness by unit category, `fly`/`march` speed, `out`/`cash` output, `train`/`build` time, `med`, `fort`, `aa`, missile `evade` and `range`. Three techs unlock units (`UNITS[t].tech`): Strategic aviation for bombers, Capital ships for cruisers, Guided missiles for cruise missiles. `aiResearch` picks by temperament, wars and the rivals' air share. The UI has a Tech tab. `load` fills in `tech`/`rs` for saves made before research.

**Combat.** Multi-sided `roundForces`, `K_DMG` 0.16. The defender gets terrain + fort + home-soil bonus (`homeBonus`: +25% on a nation's original provinces, +25% more on the capital); bunkers harden the garrison; armies standing still on friendly soil dig in (`entrench`, up to +30% after 60s, `a.since`); anti-air adds a bonus against air attackers and shoots at every air-class unit (aircraft, helicopters, missiles). Units with `ign` ignore part of all of these. Only ground units (`groundCount`) occupy and capture. `p.siege` (enemy land army present) is what stops training and building; ships and missiles alone only raid. A province is captured after `captureTime(p)` seconds of unopposed occupation: `CAPTURE_T = 20` scaled up by forts, bunkers, home soil and capital status. Home provinces also have a bigger garrison. Garrisons regenerate. Capture gives loot. An army that meets a fight on the way keeps the rest of its route in `a.held` and `resumeMarches` sends it on once nothing hostile is left there (any new order clears it). Armies move by Dijkstra pathing (`canEnter`: own land, access/alliance, or at war).
- **Roads.** Land armies stand on a road node (`a.n`) and march only along roads (`NODES`, `RADJ`, `RLEN`, `NODE_P` gives a node's province). `nodeRoute` takes the province route from `findRoute` as a corridor and `roadPath` finds the road path inside it. Routes (`a.route`) and legs (`a.mv = {from, to, fn, tn, t, dur}`, provinces and nodes) are node based; a leg inside one province keeps `a.at` set, so the army can still be fought there, while a leg across a border sets it to null. Road lengths are scaled by `ROAD_K` 0.85 so travel times match the old city-to-city ones. `orderMove(a, pid, node)` goes to the given waypoint or the city; the AI just names provinces. Fleets and missiles use city nodes (node id = province id). New units join an idle army at the city node; `mergeIdle` and the Merge button only merge armies on the same node. `enforceBorders` ejects armies from land they no longer have the right to stand on.

**Time.** Fixed step of 0.25s game time. `secondTick` runs once per game second: battles, unrest, treaty expiry, AI scheduling, rate computation. All balance is in game seconds.

**Pace.** `G.opts.pace` is game seconds per real second at 1x: Blitz 1, Quick 1/6, Long 1/24 (default), Epic 1/72 (`PACES` in `ui.js`). It is purely a UI time warp, so AI and balance are unaffected; the UI shows every timer in real time via `fmtDur` and a campaign clock (`clockText`). Speed buttons (1x/4x/16x) multiply the pace. At slow paces the frame loop advances a fractional step every frame so movement stays smooth.

**World runs while away.** `G.opts.away` (chosen at game start, toggle in Intel). Saves carry `G.wall` (real timestamp) and `G.paused`. On Continue, or when the frame loop sees a wall-clock gap over 4s (hidden tab, sleep), `catchUp` simulates the missed time in 30ms slices (capped at `MAX_AWAY` = 90 game minutes) and shows a "While you were away" summary. During catch-up `G.caretaker` is set and the player's nation is run by `caretaker()`: AI economy (recruit, build defences), defence-only `aiMilitary(n, true)`, accepts ceasefires when losing plus offered trade and non-aggression pacts. It never attacks or declares war. Paused games stay frozen. Saves from the 51-state map are refused (`saveOk`).

**No forced ending.** At 60% of population the "Dominance" modal offers Keep playing or See standings. The late game continues through coalitions against hegemons (threshold about 27% population share), unrest and uprisings. Do not add a hard win condition that stops play.

**Diplomacy.**
- Wars are stored in `G.wars` as key -> start time. IMPORTANT: `atWar` must test `!== undefined` because a war can start at t=0 (falsy).
- Treaties: truce, nap, access, trade, alliance.
- `opinion()` returns a breakdown from temperament, treaties, common enemy, border tension, hegemon fear, infamy and decaying memory events. The UI shows these reasons.
- `evalProposal` returns accept or refuse plus a reason. Alliances need a pact, trade or access deal at least 90s old (an anti-spam rule).
- Also: gifts, tribute, call to arms, join-war proposals, AI proposals to the player (ceasefire, treaties, tribute demands) handled by `answerProposal`.

**AI (`aiThink`).**
- `aiEconomy`: one ranked list of unit gaps (land mix by share, fleet `navyWant` when a rival has a coast, missiles at war), adapted to the enemy's class mix (`enemyComp`: flak and interceptors against air, helicopters and bombers against armor, patrol aircraft against subs). It saves cash for an under-strength type instead of buying cheap filler, and every other think gives construction first call (`n.ai.save` holds cash for the best project).
- `aiNavy`: fleets fight or fall back, sink enemy ships, shell ports next to their own troops' attack, defend the coast and gather in a home port. `aiMissiles`: strikes the biggest enemy stack, the dug-in focus province or a fleet in range, or moves salvos closer to the front.
- `aiMilitary`: fight-or-flee using deterministic `predictAttack`; stacks hold in an enemy province until it is captured (this fixed AI never capturing anything); defence dispatch with hold timers; opportunistic strikes; rally point and target with focus hysteresis; peacetime posture at borders; dust armies (<0.3 units) are cleaned up.
- `aiBuild` construction: scores fort/bunker/anti-air per province by threat (capped), anti-air by the rivals' air share, economy by shortage (arms industry when components run low), plus enough air bases, one level-2 air base, and naval bases up to level 3 when rivals have a coast. Projects worth less than 0.15 are skipped.
- `aiDiplomacy` and `aiWar`: opening peace (`G.grace` 240s), ambition grows with peace time, hegemons draw attention. No vultures: a nation already at war is not attacked again unless it is a hegemon (opportunists may join a one-front war if clearly stronger). Alliances are defensive: the attacker's allies only follow an offensive war against a hegemon (`wstat.by` records who started a war). Allies join wars only if they have fewer than 2 wars.

## UI notes
- Panels: Map (province/army cards), Forces, Diplomacy, Tech (research), Market, Intel. Tab labels shrink below 480px (Diplomacy shows as Diplo) so six fit. The market panel (`marketPanel`) has a row per resource with stock, rate, sell and buy price, trend, Sell 50/250, Buy 50/250 with quoted cash, and an Auto-sell button that steps through the levels. Tapping a resource chip in the top bar opens it (handled on `#res` itself, since the chips are redrawn; `#res` is only rewritten when its HTML changes). Tapping the active tab collapses the sheet.
- Interaction: drag an own army badge onto a waypoint or city to order a move (`gesture.drag`, `dragTo`, `UI.drag` holds the target province, node and preview route; the route turns red and says No route when blocked, and an ETA label sits on the target), or tap the badge and then the spot (`handleTap` passes the tap point, `mapPt` converts it, and the nearest node of that province is the target; inside the army's own province only a tap within 22px of a node moves it). Route previews, battle and capture rings (drawn around the armies in the province).
- The map draws the roads (`L.road`) and waypoint triangles (`L.wpt`, rebuilt on zoom so they keep their screen size) once zoomed in past 1.25x. Badges hang below their node on a small pin and move along the road leg (`armyPos`, `routePts`).
- Badges carry unit figures (`FIG`, `FIG_OF`, `figsOf`): a silhouette of the army's strongest arm (soldier, paratrooper, APC, tank, gun, flak truck, helicopter, jet, bomber, patrol plane, ship, submarine, missile) and a second one if that arm is at least a quarter of the army, then the unit count. `fillBadge` rebuilds a badge only when its figures, count or colour change.
- The army card (`armyStats`) lists every unit with count, attack, HP and speed after research, then firepower, toughness, speed, defence where it stands, dig-in and upkeep, and matchups (strong against, can barely hurt, vulnerable to) from `MULT`/`CM`. Pan by drag, zoom by pinch or wheel. Tiny states get an invisible hit circle.
- `UI.touch` suppresses panel re-render for 700ms after a pointerdown inside the panel so taps are not eaten by re-renders.
- The page uses `grid-template-columns: minmax(0,1fr)` on `#app` — removing it breaks the mobile layout (header and tabs overflow).
- Debug handle: `window.__flusa = { UI, S, drawMap, renderPanel }` where `S` is the SIM object.
- Hot-reload hooks: `window.claude.hot.snapshot/ready`.

## Testing
- `node test.js 20 normal` — AI-only game; expect wars, captures, eliminations, uprisings, some ceasefires and no exceptions (about 3-6s for 30 game minutes since the unit tree). The test also prints the unit and building totals and checks that no ship is inland and no fleet or salvo is mixed.
- `node smoke.js` — jsdom run through every panel; it also sells supplies, buys fuel and turns on auto-sell in the market. The final war-declaration step can be flaky from jsdom's slow requestAnimationFrame (timing, not a bug). The idle test player is often eliminated during the run; the script dismisses the Fallen modal before the save step.
- `SIM.advance(secs)` runs the world forward (used by catch-up; handy in ad-hoc balance scripts).
- Real-browser checks used headless Chromium (`@sparticuz/chromium` + `puppeteer-core`). `@sparticuz/chromium` is ESM-only: `(await import('@sparticuz/chromium')).default`. Block all http(s) requests with request interception or Google Fonts requests make screenshots hang.
- Last perf check: step 0.25ms, draw 0.16ms, panel render 0.9ms (about 17 fps in software-rendered headless, raster-bound). Draw loop is throttled to about 30 fps.

## Known gaps / ideas for next steps
- Not yet verified on a real phone; dark theme and desktop layout were not inspected by eye.
- The Intel tab once showed stale content in a headless screenshot (probably headless slowness; unconfirmed).
- Ideas: fog of war, naval and air-base mechanics, tutorial, difficulty tuning, sound, more map regions or a world map, a Godot or Capacitor port for an app.
- Balance still needs real play: AI aggression, war length, and how fast the player snowballs.
- AI-only runs (pace-independent, in game time): first nation eliminated around 7-15 game minutes, about half the original nations alive at 30 minutes. A nation left to the caretaker survives 30 game minutes roughly a third of the time (an idle one almost never), mostly because it makes no alliances.

## Style
Plain prose in explanations. Keep the code dependency-free. Prefer small, testable changes to `sim.js`, and re-run `node test.js 20 normal` after any change to the simulation or AI.
